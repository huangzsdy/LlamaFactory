## 2. 各数据集评测方法详解

### 2.1 JS通用知识理解

**数据格式**:
```json
{"question": "What is the accounting equation? A) Assets = Liabilities + Equity ...", "answer": "A"}
```

**评测方式**:
1. 将问题拼接提示词 "请直接给出答案选项字母（A/B/C/D）: {question}"
2. 使用模型生成答案
3. 从模型回复中提取 A/B/C/D 选项字母
4. 与标准答案进行匹配

**匹配规则**:
- 精确匹配: 模型回复的标准答案完全一致
- 包含匹配: 标准答案包含在模型回复中

**评估指标**: Accuracy (准确率)

---

### 2.2 代码生成

**数据格式**:
```json
{"prompt": "Write a Python function to check if a number is prime.", "test": "def is_prime(n): ..."}
```

**评测方式**:
1. 将题目拼接提示词 "请只给出Python代码，不要解释: {prompt}"
2. 使用模型生成代码
3. 提取代码块中的 Python 代码
4. **执行生成的代码**，使用 test 字段中的测试代码进行验证
5. 如果执行无错误，则判定为正确

**匹配规则**:
- 代码执行成功（无异常）: 正确
- 代码执行失败: 错误

**评估指标**: Pass@1 (通过率)

### 2.4 逻辑推理

**数据格式**:
```json

```

**评测方式**:
1. 将问题拼接提示词 "请直接给出答案: {question}"
2. 使用模型生成答案
3. 对模型回复和标准答案进行文本匹配

**匹配规则**:
- 精确匹配: 完全一致
- 包含匹配: 标准答案包含在模型回复中

**评估指标**: Accuracy (准确率)

---

### 2.5 长程依赖

**数据格式**:
```json
{"context": "The quick brown fox...", "input": "What color is the fox?", "answers": "brown"}
```

**评测方式**:
1. 将上下文和问题拼接，添加提示词 "请直接给出答案: {context} {input}"
2. 使用模型生成答案
3. 使用改进的文本匹配方式验证

**匹配规则**:
1. 精确匹配: 预测 == 标准答案
2. 词级别匹配: 标准答案的每个词都出现在预测中
3. 开头匹配: 预测以标准答案开头
4. 前100字符匹配: 标准答案出现在预测的前100个字符中

**评估指标**: Accuracy (准确率)
